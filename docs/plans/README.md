# 계획과 기술 부채

팀이 함께 보는 진행 계획과 알려진 기술 부채를 둔다. 개인 실행 기록(로그, 단계 보고서, 메모)은 계속 `.ai-output/`에 둔다.

| 위치 | 내용 | 언제 쓰나 |
|---|---|---|
| [active/](active/) | 진행 중인 계획. 파일 하나에 계획 하나: 목표, 단계와 상태, 이슈·PR, 정한 것 | PR 여러 개에 걸치는 작업. PR 하나로 끝나는 작은 변경에는 쓰지 않는다 |
| `completed/` | 끝난 계획. 끝나면 `active/`에서 옮긴다 (첫 계획이 끝날 때 만든다) | 나중에 왜 그렇게 했는지 찾을 때 |
| [tech-debt.md](tech-debt.md) | 알려진 한계와 기술 부채. 한 줄에 하나: 무엇, 근거, 제안, 담당 | 고치지 않고 넘어가는 문제를 발견했을 때 |

규칙
- 근거가 없는 항목은 쓰지 않는다. 근거는 이슈, PR, 테스트, 측정 결과처럼 다시 확인할 수 있는 것으로 남긴다.
- 정책 결정은 여기가 아니라 도메인 정책 문서(`docs/domains/<도메인>/policy.md`)와 ADR에 둔다.
