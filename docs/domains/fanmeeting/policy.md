# Fan Meeting 정책

## 1. 목표

공지한 시간대에 무작위로 열리는 10분 응모를 받고, 마감 뒤 결정적 추첨으로 당첨·예비를 정한다. 당첨자는 60분 안에 결제하고, 결제하지 않은 자리는 예비자가 순번대로 이어받는다. 승격 마감 뒤에도 남은 자리는 응모했지만 뽑히지 않은 사람에게 선착순으로 판다.

핵심 기술 목표:

- 응모 몰림을 추첨으로 경합 없이 받는다.
- 결제 결과가 늦거나 불명확해도 **정원 초과 0명, 기한 안에 결제한 사람의 자격 상실 0명**을 지킨다.
- 잠금 방식과 선착순 처리 방식을 측정으로 비교한다.

## 3. 사용자 시나리오

1. **공지 확인:** 1차 공지로 "○일 14:00~14:30 사이 10분간 응모"를 알린다. 공지 전 가입한 회원만 응모할 수 있다.
2. **응모:** 응모가 열리면 10분 안에 응모한다. 먼저 눌러도 유리하지 않다. 마감 전이면 취소하고 다시 응모할 수 있다.
3. **추첨 결과 확인:** 마감 뒤 자동 추첨으로 당첨 300명, 예비 100명을 정한다. 당첨자는 결제 마감 시각을 확인한다.
4. **결제 및 참가 확정:** 당첨자는 60분 안에 결제한다. 승인되면 참가가 확정된다. 갈 수 없으면 결제 전에 포기해 다음 사람에게 자리를 넘긴다.
5. **예비 승격:** 빈자리가 생기면 예비자가 순번대로 결제 기회를 받는다. 승격 마감(행사 24시간 전)까지 반복한다.
6. **잔여석 구매 (P1):** 승격 마감 시각에 남은 자리가 있으면 응모했지만 뽑히지 않은 사람에게 선착순으로 열린다. 결제는 10분 안에 한다.

## 5. 비기능 요구사항

| ID | 항목 | 요구사항 |
|---|---|---|
| FM-NFR-01 | 정합성 | 정원 초과 0, 중복 응모 0, 중복 주문 0 |
| FM-NFR-02 | 결제 정합성 | 기한 내 승인자 자격 상실 0, 같은 결제 이중 반영 0 |
| FM-NFR-03 | 재현성 | 같은 입력이면 같은 추첨 결과, 장애 후 재실행도 같음 |
| FM-NFR-04 | 응답 정합성 | 커밋된 응모 수 = 성공 응답 수 |
| FM-NFR-05 | 동시성 | 행사 행 기준 잠금, 잠금 순서 고정 |
| FM-NFR-06 | 성능 | p50/p95/p99, 실제 RPS, 5xx, Hikari 대기, 잠금 대기 측정 |
| FM-NFR-07 | 복구 | 서버 재시작 뒤 DB에서 미처리 작업을 찾아 이어감 |
| FM-NFR-08 | 보안 | 본인 주문만 조회·결제·포기, 다른 회원 주문은 404 |

정합성 목표는 확정이다. 성능 목표 수치는 S1 측정(3만 명, 1,000·3,000 RPS) 결과로 정한다. 측정 환경은 앱·DB·부하 발생기를 다른 머신에 둔다.

## 6. 비즈니스 정책

| 영역 | 정책 |
|---|---|
| 응모 시간 | 10분 고정. 먼저 눌러도 유리하지 않음 |
| 응모 자격 | 1차 공지 예정 시각(`first_notice_scheduled_at`) 전 가입 회원 |
| 중복 응모 | 회원당 행사별 1건 |
| 재응모 | 마감 전 가능, 같은 행 재사용 |
| 마감 판정 | 마감 시각 전에 확인되고 마감 처리보다 먼저 저장(커밋)된 응모 |
| 당첨·예비 | 기본 300명·100명, 행사별 조정 |
| 결제 기한 | 주문 발급 후 60분 (잔여석 10분). PG 승인 시각 기준, 기한과 같으면 인정 |
| 결제 재시도 | 실패 확정 시 기한 안에서 허용 |
| 결과 불명확 | 자리 유지, 자동으로 확정·탈락하지 않음. 1분 재조회, 30분 넘으면 경고 (운영자 처리는 P1) |
| 늦은 승인 | 자격 없음, 환불 대상 |
| 결제 포기 | 결제 시도 전에만, 되돌릴 수 없음. 바로 다음 예비 승격 |
| 예비 승격 | 빈자리만큼 순번대로 일괄 |
| 야간 승격 | 23:00~09:00 중지 |
| 승격 마감 | 기본 행사 24시간 전. 마감 60분 전 이후 승격 없음 |
| 잔여석 (P1) | 승격 마감 ~ 행사 3시간 전, 미선발 응모자, 결제 10분, 재구매 불가 |
| 최종 명단 | 행사 3시간 전 확정 |
| 탈퇴 | 진행 중 참여가 있으면 차단, 추첨·승격 때 탈퇴자 제외 |
| 모집 완료 | 보류만 막고, 환불 대기는 막지 않음 |
